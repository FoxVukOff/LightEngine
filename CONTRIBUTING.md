# как участвовать

## требования

- python 3.11 и новее
- PyQt6 для редактора и плеера
- pyinstaller только если собираешь exe

```bat
pip install -r requirements.txt
python main.py
```

## перед коммитом

```bat
python tests\run_tests.py
python tests\run_editor_test.py
```

`run_tests.py` проверяет язык и ядро, `run_editor_test.py` прогоняет редактор в
offscreen. оба должны закончить строкой `all ok` и `editor ok`.

если трогал рендер или сборку, проверь ещё:

```bat
set LE_SELFTEST=1 && python main.py
set LE_SELFTEST=1 && dist\игра.exe
```

## стиль кода

- комментарии и сообщения об ошибках строчными, без точки в конце
- тире только обычное `-`, кавычки только прямые
- без лишних абстракций: плоские функции, без фабрик и базовых классов ради одного случая
- имена как в жизни: `buf`, `idx`, `cfg`, `ctx`, `n`, `k`, `v`
- недоделки помечай `# todo:` или `# fixme:`, а не заполняй выдуманным кодом

## версии

отдельной системы версий нет, история хранится в коммитах git.
значимые изменения делай отдельным коммитом с коротким сообщением в нижнем регистре.
